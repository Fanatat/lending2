# vanatat.ru — сайт-портфолио

Личный сайт Валерия ([Fanatat](https://github.com/Fanatat)) о системах на ИИ-агентах: игры, боты, мониторинг и автоматизация.
Тёмный интерфейс в стиле лабораторного терминала с интерактивными демонстрациями. Есть русская ([vanatat.ru](https://vanatat.ru/)) и английская ([vanatat.ru/en](https://vanatat.ru/en/)) версии.

![Главная страница](docs/screenshot.jpg)

## Что на сайте

- **Восемь систем.** У каждой своя страница: студия браузерных игр, датчик воздуха HP100, автопилот каналов, контент-завод, штаб ИИ-агентов, мониторинг периметра и другие.
- **Живой виджет HP100.** Показывает CO₂, температуру, влажность и пыль домашнего датчика на ESP32. Если показание старше 20 минут, виджет помечает его как устаревшее и пишет время замера. Если источник недоступен, виджет переходит на демонстрационные данные с пометкой «нет связи».
- **Игры студии.** Четыре опубликованных игры ведут в VK Игры.
- **Форма заявки.** Валидация есть и в браузере, и на сервере.

Демонстрационные блоки подписаны честно. Например, цифры портфеля в блоке All in сгенерированы и не являются реальным счётом.

## Стек

Next.js 14, React 18, TypeScript, Tailwind CSS, Three.js (интро), Framer Motion, Lenis, zustand.

## Запуск

Нужны Node.js 22 и npm.

```bash
git clone https://github.com/Fanatat/lending2.git
cd lending2
npm ci
npm run dev        # http://localhost:3000
```

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`.

## Проверки и выкладка

- **CI** ([checks.yml](.github/workflows/checks.yml)). Запускается на каждый pull request и каждый пуш в `main`. Собирает статический экспорт и прогоняет smoke-тест [scripts/smoke.mjs](scripts/smoke.mjs). Тест открывает каждую страницу из `sitemap.xml` в headless Chromium (Playwright) и падает на любой ошибке консоли, в том числе на расхождениях гидратации.
- **Выкладка** ([pages.yml](.github/workflows/pages.yml)). После слияния в `main` сайт сам собирается статическим экспортом и публикуется на GitHub Pages под доменом vanatat.ru.
- Изменения идут только через pull request.

## Устройство

- `app/` — страницы: главная, `en/`, `projects/[slug]`, OG-картинка, sitemap, robots.
- `components/` — интро, секции систем, пасхалки, эффекты.
- `lib/` — данные и логика: проекты, статусы систем, источник HP100, адреса и ссылки.
- `public/` — звуки (лицензии в `public/sounds/CREDITS.md`) и текстуры.

Код сайта писали ИИ-агенты (Claude Code). Валерий ставил задачи, принимал результат и выпускал сайт.
