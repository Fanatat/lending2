# lending2 — lab-terminal-portfolio

Личный сайт-портфолио в тёмной терминальной эстетике — витрина реальных
проектов, показанных не текстом, а работающими прямо на странице
механизмами.

## Стек

- Next.js 14 / TypeScript
- Tailwind CSS
- Framer Motion, Lenis (плавный скролл)

## Особенности

- Живой виджет HP100: показывает актуальные показания датчика воздуха,
  подтягивая данные с отдельного сервера в реальном времени.
- Интерактивная сетевая карта, консольные пасхалки и другие скрытые детали
  по всей странице.
- Полностью тёмная тема без единого светлого варианта, минимум декоративных
  элементов — акцент на типографике и линейной инфографике.

## Разработка

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

## Продакшн-сборка

```bash
npm run build
npm run start
```
