# Сайт-портфолио Валерия (lending2 / vanatat.ru) — игры, боты и автоматизация

## Что это и для кого

Сайт-портфолио `lending2` (репозиторий `Fanatat/lending2`, пакет `lab-terminal-portfolio`, адрес https://vanatat.ru/) — личный
сайт Валерия (основатель студии «Пятница») для работодателей и заказчиков ИИ-автоматизации. Тёмный интерфейс в стиле
лабораторного терминала с интерактивными демонстрациями, анимацией и скрытыми пасхалками. На странице можно открыть
игры студии в VK, посмотреть живые показания домашнего датчика воздуха HP100, познакомиться с восемью «системами»
автоматизации и оставить заявку через форму. Есть русская версия (`/`) и английская (`/en/`).
Другие названия: «Привет от Валеры» (заголовок вкладки), «лендинг 2», lending2, vanatat.

## Разработка и сборка (Next.js 14)

Стек: Next.js 14, React 18, TypeScript, Tailwind CSS, Three.js (интро с планетами), Framer Motion, Lenis (плавный скролл), zustand. Нужны Node.js 22 (версия CI), npm и Git.

```bash
git clone https://github.com/Fanatat/lending2.git
cd lending2
npm ci
# Необязательно: cp .env.local.example .env.local
npm run dev
```

Сайт откроется на http://localhost:3000. Проверки и сборка:

```bash
npm run lint
npm run typecheck
npm run build
npm run start
```

Статический экспорт для GitHub Pages: `PAGES_BASE_PATH=/lending2 npm run build`, результат в `out/` (то же делает workflow). Обычная сборка запускается Node.js-сервером через `npm run start`.

## Проверки в браузере (smoke) и CI

Smoke-проверка `scripts/smoke.mjs` читает `sitemap.xml`, открывает каждую страницу и скрытую `/projects/bridge/` в headless Chromium и падает при любой ошибке консоли (так ловятся hydration-расхождения). Запуск: `npx playwright install chromium`, затем при работающем сайте `SMOKE_BASE_URL=http://localhost:3000 npm run smoke`. Запрос HP100 к `api.vanatat.ru` скрипт подменяет образцом ответа: с localhost эндпоинт не отвечает из-за CORS. В GitHub Actions workflow [checks.yml](.github/workflows/checks.yml) на каждый pull request и каждый пуш в `main` собирает статический экспорт, поднимает его через `python3 -m http.server 3000 --directory out` и гоняет smoke. Playwright закреплён в `package.json` (1.62.0).

## Данные на странице: живой виджет HP100

HP100 (виджет воздуха, `components/sections/hp100/HP100Widget.tsx`, источник `lib/hp100-live.ts`) показывает CO₂, температуру, влажность и пыль домашнего датчика. Цепочка: браузер → `https://api.vanatat.ru/site/air` → мост на домашнем сервере → сервер платы (`~/projects/utility/health_air/airmonitor_vps.py`, служба `airmonitor.service`, на 2026-10-15 active). Браузер опрашивает эндпоинт раз в минуту (ответ кешируется на 30 секунд) и получает последнее измерение с его временем и историю за 24 часа шагом 15 минут. CORS разрешён только для своих адресов (vanatat.ru, www, fanatat.github.io, vanatat.vercel.app); код 502 означает, что сервер платы выключен. Показание старше 20 минут помечается как устаревшее и выводится со временем замера, а не как «живое». Если эндпоинт недоступен совсем, включается демонстрационный источник `lib/mock/hp100.ts` с пометкой «нет связи». Сервер платы раньше выключали на ночь (ориентировочно 21:00–05:30 МСК); при проверке 2026-10-15 01:01 МСК показание было свежее (`updated` 22:01Z), поэтому актуальный график работы не подтверждён.

Остальные данные: портфель в блоке All in — сгенерированные демонстрационные значения, не реальный счёт; игры и системы — демонстрации и ссылки на отдельные сборки.

## Форма заявки

В блоке контактов (`components/sections/closing/LeadForm.tsx`, RU и EN, добавлена 2026-10-14) посетитель оставляет имя (необязательно), контакт (почта, @ник Telegram или телефон) и описание задачи (10–3000 символов). Форма отправляет JSON на `https://api.vanatat.ru/site/lead` (n8n за прокси сервера); адрес задаётся `NEXT_PUBLIC_LEAD_URL` или значением по умолчанию в `lib/site.ts`. Валидация дублируется на сервере. Подпись на форме честно сообщает, что текст раскладывает на пункты Google Gemini. Кнопки связи: Telegram `t.me/fanatat` и MAX (`MAX_URL` в `lib/site.ts`); телефона и почты на сайте нет. GET-запрос к эндпоинту формы возвращает 403 — это нормально, принимается только POST со своего сайта.
