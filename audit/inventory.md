# Инвентаризация сайта-портфолио

Дата обхода: 27.09.2026. Основной адрес: https://vanatat.vercel.app (Vercel, HTTPS).
Второй адрес: http://vanatat.ru (GitHub Pages; на него ведёт профиль автора на GitHub,
туда же перенаправляет https://fanatat.github.io/lending2/). Сайт на обоих адресах собран
из одного кода, ветка `main`, репозиторий https://github.com/Fanatat/lending2.

Как получены данные: `audit/scripts/crawl.py`, `hosts_check.py`, `repos_check.py`.
Сырые результаты лежат в `audit/data/pages.json`, `links.json`, `hosts_check.json`, `repos_check.json`.

## Допущения (в ТЗ не заполнено)

В брифе остались незаполненными поля «Сайт», «Адресат» и «Желаемое действие». Ниже то, что я вывел из контента сайта. **Это допущения.**

- **Адресат.** Во-первых, люди с задачей по автоматизации или ИИ-агентам: в финальном блоке сказано «Если у вас есть такая задача… напишите». Во-вторых, рекрутеры: комментарий в `app/en/page.tsx:150` прямо говорит «English entry point for recruiters coming from LinkedIn», а блок «КТО ЗА ПУЛЬТОМ» в `OperatorSection.tsx:5` помечен «Recruiter-facing».
- **Желаемое действие.** Написать в Telegram (@fanatat). Запасной вариант — написать в MAX. Это единственные два призыва к действию на сайте (`ClosingSection.tsx:254-272`). Второстепенное действие — перейти на GitHub (`OperatorSection.tsx:32`).

**Главное из обхода**

- В DOM главной всего **7 ссылок `<a href>`**: RU, EN, GitHub, Telegram, MAX и две атрибуции в подвале.
- Все 8 страниц проектов открываются только по клику на `div role="button"` с `router.push()` (`components/transitions/ProjectCardLink.tsx:43-48,67`). Кнопки «← на дашборд», «предыдущая» и «следующая» тоже реализованы как `<button>` (`ProjectShell.tsx:48,86,97`).
- Поисковик, превью ссылок в мессенджерах и «открыть в новой вкладке» не видят ни одной страницы проекта. Карты сайта (sitemap) нет.
- На всех страницах проектов `canonical` и `og:url` указывают на главную (`data/hosts_check.json`). Для поисковика это дубли главной.
- Навигации между разделами нет: левая «шкала» `TrunkNav` по коду декоративная (`TrunkNav.tsx:28`, «doesn't act as a navigation control»).
- На всех страницах, включая `/en` и `/projects/*`, при каждом заходе показывается интро (`IntroGate` в `app/layout.tsx:101`).

**Итого по реестру**

- В реестре 9 позиций верхнего уровня (8 систем + сам сайт) и 5 игр внутри «Пятницы».
- **Ни у одного проекта нет с сайта ссылки на код или на запускаемое демо.**
- Для 5 игр публичные сборки существуют (проверены в `data/projects_check.json`), для сайта есть второй адрес. У остальных систем внешних демо нет по природе: боты, железо, приватные данные.

## Ключевые сценарии посетителя

Сценарии прогнаны скриптом `audit/scripts/scenarios.py`. Результаты — в `data/scenarios.json` и `screenshots/scenarios/`.

1. **S1 «Заказчик»:** зашёл на главную → прошёл интро → понял, кто автор («КТО ЗА ПУЛЬТОМ») → открыл проект HP100 → вернулся на дашборд → написал в Telegram.
2. **S2 «Сразу написать»:** зашёл на главную → ищет контакт на первом экране → листает до кнопки «Написать в ТГ» → нажал.
3. **S3 «Рекрутер EN»:** зашёл на `/en` → прочитал, кто автор → перешёл на GitHub → вернулся → «Message on Telegram».
4. **S4 «Пришёл по ссылке на проект»:** получил ссылку `/projects/hp100` → понял, что это → ищет контакт автора → вернулся на дашборд → Telegram.
5. **S5 «Хочу поиграть»:** главная → студия «Пятница» → нажал на картридж игры → ищет, где сыграть.
